POSSESS 0.9 — Windows 플레이테스트 빌드

ZIP을 폴더에 풀고 POSSESS.exe를 실행하세요.
POSSESS.pck는 실행 파일과 같은 폴더에 있어야 합니다.
Godot 편집기 설치는 필요하지 않습니다.

타이틀에서 Enter: 안전한 연습부터 시작 / Tab: 연습 건너뛰기
WASD 이동 / 좌클릭 공격 / 우클릭 빙의
Shift 회피 / Space 점프 / F 길게 상호작용 / R 재장전 / E 몸 이탈
Esc: 일시정지, 몸 정보, 설정, 조작 키 변경, 지난 원정

기본 유령은 느린 영혼탄을 쏩니다. 적을 약화한 뒤 빙의하세요.
빙의하면 해당 몬스터의 무기를 사용합니다.
방을 정리한 뒤 증강을 고르고 열린 문에서 F를 길게 누르세요.
현재 몸을 다음 방에도 가져갑니다.

유령 해금, 기기 설정, 변경한 키와 최근 완료·사망 기록은 자동 저장됩니다.
진행 중인 원정 이어하기는 없습니다. 게임을 종료하면 현재 판은 끝납니다.
기존 개발 버전과 같은 사용자 저장 경로를 사용합니다.

아직 출시판이 아닙니다. 한국어, 키보드·마우스, 로컬 싱글플레이 빌드입니다.
최종 아트·사운드, 영어 번역, 추가 성능 안정화와 외부 플레이테스트가 남아 있습니다.
