# POSSESS UI 스타일 가이드 v1

목업 원본: `docs/ui/*.dc.html` (HTML 안의 px·색·폰트 값이 스펙이다. 그대로 옮길 것.)
목업 링크(브라우저·PNG 내보내기): 대화에서 공유된 Artifact.

## 방향
어둡고 차가운 지하(다크틸) 위에 두 가지 온도의 강조색: **민트 = 유령·빙의·안전**, **오렌지 = 몸·부패·위험**. 보라는 성장(영혼 레벨·증강)에만. 장식은 얇은 선·마름모 점·1px 테두리로 절제. 둥근 모서리 없음(0px). 그라데이션은 배경 대기감에만, UI 요소에는 쓰지 않음.

## 폰트 (전부 SIL OFL — 상용 무료, TTF 동봉 가능)
- **Cinzel** 600/800 — 숫자(수명 초, 탄창, 확률 %), 워드마크 POSSESS. 라틴 전용.
- **Noto Serif KR** 700/900 — 제목·몸 이름·카드 제목 (한글 디스플레이).
- **Noto Sans KR** 400/500/700 — 본문·라벨·안내.
- Godot: `theme/` 폴더에 TTF 넣고 Theme 리소스의 default_font를 Noto Sans KR로, 제목/숫자용 LabelSettings 2종 추가.

## 타입 스케일
워드마크 18(자간 0.32em) · 화면 제목 40 · 카드 제목 26 · 몸 이름 22 · 큰 숫자 44 · 본문 14 · 라벨 12~13(자간 0.1em).

## HUD 규칙
- 상시 노출은 4곳뿐: 좌상(스테이지), 우상(남은 적), 좌하(몸·수명), 우하(무기·탄창). 하단 중앙에 영혼 성장 바(3px, 얇게).
- 조준점 주변이 "상황 정보"의 유일한 자리: 표적 이름·체력·빙의 %·거리. 회피 쿨다운은 조준점 좌하단 작은 호(텍스트 없음).
- 수명 바는 10칸 분절. 25% 이하에서 danger 색.
- 상시 텍스트 안내("위장 · 공격하면 풀립니다" 등)는 제거. 상태 변화는 1.5초 토스트 1줄로만, 한 번에 하나.
- 아이콘 자리: 72×72 panel 박스. 실제 아이콘 전까지 선화(SVG) 자리 표시.

## 카드 규칙 (증강 선택)
- 카드 376×(내용) · 상단 3px 색 띠 = 카테고리(보라=유령, 오렌지=몸, 민트=빙의).
- 순서: 번호·태그 → 일러스트 자리(150px) → 제목 → 설명 2줄 → 수치 변화 박스(전→후, 후는 민트 굵게) → 조합 힌트 1줄 → 선택 버튼.
- 등급 표시는 마름모 점 2개(단계).
- 추천/호버 카드는 민트 테두리 + 8px 상승 + 버튼 채움.

## 아이콘 제작 브리프 (2D, 나중에 생성/외주)
스타일: 단색 선화 1.5px, 24 그리드, 모서리 둥글림, 배경 없음. 색은 코드에서 입힘(흰색 원본).
목록(20): 몸 6(연발병·망치병·산탄병·서리궁수·화염술사·번개술사) / 증강 6(유령탄·몸수명·빙의확률·첫공격·부패공격·몸폭발) / 유물 3(나침반·모래시계·불씨) / 속성 3(불·얼음·번개) / 상태 2(화상·둔화).
초상화 6(몸별, 정사각 256): 상반신, 어두운 배경, 림라이트 민트.
키아트 1(1000×720): 유령이 병사의 등 뒤로 스며드는 순간, 민트 발광 vs 오렌지 부패.
